## The entry

A two-part micro-confession: a `To:` line naming who the unsent message
was meant for, and the unsent message itself, one line written exactly as
it was typed. Specific, honest, and with a felt reason it stayed in drafts.

## Run

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py out.txt    # or to a path of your choice
```

Pure Python standard library, no dependencies. Output is deterministic:
139 characters total, message line 117 characters (gate: 1–260 total,
message at most 200).
